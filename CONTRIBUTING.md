# Contributing to the project hub

The site is intentionally static. Its project cards are generated from `projects.json`.

## Add or update a project

1. Add a project record to `projects.json` with its category, concise purpose, current stage, useful starting context, and contribution links.
2. Keep claims factual and grounded in the project's README or roadmap. Link to the project's issues rather than duplicating its task list here.
3. Use an existing category where it fits. Add a category only when there is at least one project to show in it.
4. Preview the page locally using the command in the README and check that search, filters, and links work on desktop and mobile.

The hub is an invitation and index, not a second source of truth. Code, issues, roadmaps, and contribution instructions belong in each project's repository.
